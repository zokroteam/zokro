How to play

Control in the game &quot;Om Nom: Pursuit&quot; on the computer is carried out using arrows, and on touch screens using swipes. The goal of Om Nom Run is for you, as a player, to complete a set of challenges in each level. Each level presents a different challenge, such as covering the required distance, performing tricks or collecting letters. Avoid collisions by moving left and right, as well as jumping and diving under obstacles. For each successfully completed level, you receive a star rating. While running, you need to collect gold coins and various bonuses, thanks to which new game possibilities open up. You can buy new characters from the Nomville universe, as well as stylish outfits using the collected coins.
