How to play

Fill in the shapes with the correct blocks. Make sure all colors borders fit. Tangram Puzzle 2.0 is a new kind of Tangram. You must drag and drop the blocks inside the empty shapes. All block borders have colors and these colors should match with the colors of the adjacent blocks. If it doesn’t match, it is not good. If all colors match… you win and you can go to the next level
