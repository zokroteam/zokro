How to play

Piggy Bank Demolish Run is a fun and classic 3D pixel-running arcade game. You have to grab special game coins to pass the toy walls. You will fail the game if you hit any red obstacles or traps. You can unlock and use 21 skins in the shop if you collect many gold coins while running. Different toy walls need different game coins, pick the least ones to pass them.
