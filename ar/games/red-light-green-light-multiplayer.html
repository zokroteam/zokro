إزاي تلعب

Now, this red light folk game is available on smartphones and you can play it anywhere, whenever you want. The game is simulated from real traffic lights, when there is a green light you are allowed to move freely, but when there is a red light you are forced to stop motion. If you still deliberately move when there is a “redlight”, you will definitely have to pay the price. Now your motion supervisor is a doll. Try to run as fast as you can to the finish line without being detected by the doll. You have to try to run fast and touch the wall because only the first 5 people to the finish line can survive. If you are not in the top 5, the worst will come to you.
