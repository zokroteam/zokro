💧 Desert Daily

★★★★★ 4.8 • 🎮 daily • 📱 Mobile OK

🏆 Meilleurs joueurs

⛶ Plein écran

Comment jouer

Vous commencez avec 100 d'eau. La chaleur augmente toutes les 10 secondes et évapore votre eau. Utilisez 3 boutons : Boire (+8 eau), Ombre (-chauffe, coûte de l'eau), Repos (+score mais +chaleur).

Survivez aux 60 secondes complètes pour gagner. Même défi pour tout le monde aujourd'hui - comparez les scores avec vos amis.

Astuces

  • Ne buvez pas tôt - enregistrez le score pour les 20 dernières secondes chaudes.
  • Utilisez l'abat-jour juste avant que la chaleur ne franchisse 50 degrés.
  • Ne vous reposez que lorsque l'eau est supérieure à 60.

FAQ

Desert Daily est-il gratuit ? Oui, gratuit pour toujours sur Zokro, pas d'inscription.

Est-ce que ça change tous les jours ? Oui, le modèle de chaleur change tous les jours, même chose pour tous les joueurs.

Puis-je partager mon score ? Oui, appuyez sur Copier le résultat et collez-le n'importe où.
